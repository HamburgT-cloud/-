単語トレーナー p.280まで（オフライン対応）

単語帳の索引から、ページ数が280以下の単語（3,228語）を4択クイズにしたサイトです。
複数のページが書かれた単語は、どれか1つでも280以下なら入れています。
正解・不正解の表示に、その単語のページ数（p.〇〇）が出ます。

■ 使い方
  公開されたURLをスマホのSafariで開き、共有ボタン > ホーム画面に追加。
  一度開けば、その後は圏外でも使えます。

■ 記録について
  学習記録と「箱」は、使っている人の端末のブラウザの中に保存されます。
  人それぞれ別々なので、URLを共有しても他の人の記録とは混ざりません。
  ブラウザのサイトデータを消すと記録も消えます。

■ 単語を直したいとき
  words.csv をExcelで開き、word / pos / meaning を編集して「CSV UTF-8」で保存。
  アプリの「データの管理」から取り込みます（取り込んだ内容はその端末だけに反映）。
  全員に反映したいときは、index.html の単語データを直して上げ直します。
